# Plugins & Custom Modules Directory
Folder ini disiapkan untuk ekspansi fitur AntiHalu di masa depan:
- **Custom Attack Vectors**: Strategi jailbreak baru, persona prompts, tokenizer attacks.
- **Custom Evaluators / Judges**: Model-as-a-judge scorers, refusal classifier weights.
- **Custom Providers**: Integrasi inference gateway lokal (Ollama, vLLM, LMStudio, Aphrodite).
