Frequently Asked Questions

How does AntiHalu prevent false-positive over-refusal?

+
Frontier models frequently refuse legitimate technical requests due to coarse keyword filters. AntiHalu systematically isolates and tests semantic framing permutations, locking the optimal prefix/prefill protocol into your Hermes agent config to restore adherence without compromising safety standards.

What is the Parseltongue Vault?

+
The Parseltongue Vault is an adversarial query encoding engine that generates 11 to 33 obfuscated variants of a given prompt using homoglyphic substitution, leetspeak, Morse, Braille, and zero-width spaces to benchmark the robustness of input guardrails.

How are API credentials and tokens managed?

+
AntiHalu operates entirely client-side or on your private local server instance. Tokens from CLI sessions (Claude Code, OpenAI Codex, Antigravity) are auto-detected locally without ever leaving your machine.

Can I export audit data for compliance reporting?

+
Yes. Every module features one-click multi-sheet Excel (.xls) exports formatted with executive KPI cards, embedded visual diagram bars, and complete forensically verifiable logs.
